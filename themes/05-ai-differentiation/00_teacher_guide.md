# 00. Методическое руководство (внутренний файл)

> Файл для преподавателя. В основной студенческий маршрут не включается.

---

## 🎯 Цель темы
Организовать работу так, чтобы студент:
1. выбрал свою дисциплину и узкую тему;
2. собрал три уровня материалов (`basic/standard/advanced`);
3. назначил уровень по предтесту;
4. подтвердил выдачу уровня через обязательный линейный Albato-маршрут.

---

## 📦 Обязательный результат части A
1. `A1` Паспорт модуля + предтест.
2. `A2` Комплект трех уровней.
3. `A3` Протокол маршрутизации + подтверждение прогонов.

Формат сдачи: **3 отдельных файла**.

---

## 🧭 Рекомендуемый маршрут двух занятий
### Занятие 1 (90 минут)

| Интервал | Блок | Что делает студент | Что проверяет преподаватель |
|---|---|---|---|
| 0-10 | запуск | фиксирует `discipline/topic/audience` | формулировка темы не слишком широкая |
| 10-35 | A1 | собирает паспорт и предтест (6 вопросов) | есть ключ и шкала `0-2/3-4/5-6` |
| 35-70 | A2 | собирает `basic/standard/advanced` | уровни реально различаются |
| 70-90 | A2 | добавляет checkpoint в каждый уровень | checkpoint проверяем по ключу |

### Занятие 2 (90 минут)

| Интервал | Блок | Что делает студент | Что проверяет преподаватель |
|---|---|---|---|
| 0-35 | A3 | настраивает `Yandex Forms -> Albato -> Google Sheets` | поток линейный и рабочий |
| 35-60 | A3 | выполняет 3 тестовых прогона (`2/6`, `4/6`, `6/6`) | маршрутизация уровней корректна |
| 60-80 | B | выполняет один light-вариант части B | есть фактическая доработка |
| 80-90 | защита | готовит пакет `A1/A2/A3` + B | комплект применим на занятии |

---

## ✅ Правила зачета
1. Шкала предтеста фиксированная: `0-2 -> basic`, `3-4 -> standard`, `5-6 -> advanced`.
2. Albato-маршрут обязателен для части A.
3. В части B не дублируется основной результат A.
4. Рубрика — шкала `0-2` по критериям из файла `07`.

---

## 📝 Контрольный чек-лист преподавателя
1. Есть ли в `A1` заполненные `discipline`, `topic`, `audience`, `learning_goal`?
2. Есть ли в `A1` предтест из 6 вопросов и `answer_key`?
3. Есть ли в `A2` три уровня и checkpoint + key для каждого?
4. Есть ли в `A3` `flow_steps`, `field_mapping`, `routing_rules`, `run_evidence`, `result_log`?
5. Подтверждены ли прогоны `2/6`, `4/6`, `6/6`?
6. Не перегружен ли текст техническими деталями, не нужными студенту?

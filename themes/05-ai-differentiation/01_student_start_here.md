# 01. Регламент запуска

---

## Назначение работы
В рамках темы требуется разработать индивидуальный адаптивный мини-модуль по выбранной дисциплине и узкой теме.  
Результат оформляется в трех артефактах: `A1`, `A2`, `A3`.

---

## Ключевые понятия
- `A1`: структурированный паспорт модуля и предтест.  
  Назначение: фиксирует исходные параметры и правило выбора уровня.
- `A2`: комплект материалов для уровней `basic`, `standard`, `advanced`.  
  Назначение: обеспечивает дифференциацию содержания по уровню подготовки.
- `A3`: протокол маршрутизации `Yandex Forms -> Albato -> Google Sheets`.  
  Назначение: подтверждает автоматическое назначение уровня и регистрацию результата.

---

## Последовательность выполнения
1. Сборка `A1` по файлу `02`.
2. Сборка `A2` по файлу `03`.
3. Сборка `A3` по файлу `04`.
4. Выполнение A-core по файлу `05`.
5. Выполнение одного варианта части B по файлу `06`.
6. Проверка по рубрике из файла `07`.

---

## Операционный контур выполнения

| Этап | Действие | Ожидаемый результат | Фиксация результата |
|---|---|---|---|
| `A1` | формализация исходных параметров и предтеста | назначение уровня по шкале | файл `A1` |
| `A2` | проектирование трех уровней | различимые уровни с checkpoint | файл `A2` |
| `A3` | настройка линейной маршрутизации | автоматическая регистрация уровня | файл `A3` |
| `B` | ограниченная доработка | подтвержденный прирост качества | файл/фрагмент части B |

---

## Нормативные требования
1. Предтест содержит `6` вопросов.
2. Уровень определяется только по шкале:
   - `0-2` -> `basic`,
   - `3-4` -> `standard`,
   - `5-6` -> `advanced`.
3. Для каждого уровня в `A2` фиксируются `checkpoint_test` и `checkpoint_key`.
4. В `A3` подтверждаются сценарные прогоны `2/6`, `4/6`, `6/6`.

---

## Входной самоконтроль
1. Определены ли `discipline` и узкий `topic`?
2. Подготовлен ли формат трех отдельных файлов (`A1`, `A2`, `A3`)?
3. Понятна ли роль каждого артефакта в общей логике задания?

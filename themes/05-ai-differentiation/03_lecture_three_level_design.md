# 03. Проектирование трех уровней (A2)

---

## 🎯 Зачем этот материал
На этом шаге вы собираете артефакт `A2`: полноценный комплект материалов для уровней `basic`, `standard`, `advanced`.

---

## 🧱 Схема A2 (для каждого уровня)
Для каждого уровня обязательно заполнить:
- `theory`
- `practice_block`
- `checkpoint_test`
- `checkpoint_key`
- `criteria`
- `teacher_notes`

---

## 🧭 Принцип дифференциации
Тема и цель едины для всех трех уровней.  
Меняются глубина, объем самостоятельности и тип операций мышления.

---

## 🧭 Шаг 1. Сформируйте каркас трех уровней
### Действие
Для каждого уровня зафиксируйте:
1. что студент изучает (`theory`);
2. что делает руками (`practice_block`);
3. как быстро проверяет понимание (`checkpoint_test` + `checkpoint_key`);
4. по каким признакам оценивается (`criteria`);
5. какие подсказки даются преподавателю (`teacher_notes`).

### Ожидаемый результат
Есть три разные версии одного учебного модуля, а не один и тот же текст разной длины.

### Что сдавать
Черновик структуры `A2` по всем трем уровням.

---

## 🧭 Шаг 2. Разведите уровни по сложности
### Действие
Используйте правило:
- `basic`: больше опор и пошаговых подсказок;
- `standard`: меньше подсказок, больше самостоятельного выбора;
- `advanced`: перенос в новую ситуацию + объяснение причин ошибок.

### Ожидаемый результат
Различия уровней видны по типу задач, а не только по формулировкам.

### Что сдавать
Краткую матрицу различий между тремя уровнями в составе `A2`.

---

## 🧭 Шаг 3. Добавьте checkpoint для каждого уровня
### Действие
На каждом уровне добавьте короткий `checkpoint_test` (2-4 задания) и `checkpoint_key`.

### Ожидаемый результат
Понимание уровня можно быстро проверить и автоматизировать через Albato.

### Что сдавать
Блоки `checkpoint_test` и `checkpoint_key` внутри каждого уровня в `A2`.

---

## ✅ Мини-шаблон уровня в A2

```text
level: basic|standard|advanced
theory:
practice_block:
checkpoint_test:
checkpoint_key:
criteria:
teacher_notes:
```

---

## 📝 Проверка перед переходом к A3
1. Есть ли полный набор полей у каждого уровня?
2. Есть ли отдельный checkpoint и ключ у каждого уровня?
3. Можно ли по материалу провести занятие без дополнительной расшифровки?

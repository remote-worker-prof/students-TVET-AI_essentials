# 04. Линейная маршрутизация: артефакт A3

> Историческое имя файла сохранено для совместимости ссылок.

---

## Назначение артефакта A3
После проектирования содержания в `A2` необходим шаг, который подтверждает практическую работоспособность назначения уровня.  
Именно эту функцию выполняет `A3`: он связывает результат предтеста и выдачу учебного материала через воспроизводимый поток.

Линейная схема выбрана сознательно: она проще в сопровождении и легче в проверке.

---

## Сквозной демонстрационный образец
В демонстрационном кейсе (информатика, `if/else`) поток работает следующим образом:
1. предтест фиксирует `score`;
2. Albato применяет шкалу `2/4/6`;
3. в журнал записывается `assigned_level` и ссылка на нужный материал.

Такой пример помогает увидеть, как формальный балл превращается в конкретную учебную траекторию.

---

## Структура A3
Обязательные разделы:
- `flow_steps`
- `field_mapping`
- `routing_rules(2/4/6)`
- `run_evidence`
- `result_log`

---

## Ключевые понятия
- `flow_steps`: последовательность операций маршрута.  
  Почему это важно: исключает неявные ручные действия.
- `field_mapping`: соответствие полей между системами.  
  Почему это важно: предотвращает потерю смысла данных при передаче.
- `result_log`: журнал конечных записей.  
  Почему это важно: подтверждает корректность выполнения маршрута на фактах.

---

## Шаг 1. Последовательность потока
### Переход
После фиксации структуры `A3` сначала требуется определить общий контур маршрута.

### Почему шаг необходим
Без фиксированной последовательности нельзя проверять корректность переходов между системами.

### Действие
Фиксируется линейный маршрут:
`Yandex Forms -> Albato -> Google Sheets`.

### Ожидаемый результат
Схема потока описана без условных ветвлений и без неявных переходов.

### Фиксация результата
Раздел `flow_steps` в `A3`.

### Короткий пример
`flow_steps`: «получение ответа -> расчет балла -> запись уровня -> запись ссылки».

---

## Шаг 2. Сопоставление полей
### Переход
После описания маршрута необходимо согласовать, какие данные переносятся между этапами.

### Почему шаг необходим
Если поле передается без явного соответствия, результат может быть записан неверно даже при корректной логике маршрута.

### Действие
Заполняется `field_mapping` по полям:
`discipline`, `topic`, `score`, `assigned_level`, `material_link`.

### Ожидаемый результат
Каждое поле имеет однозначный путь от источника к журналу.

### Фиксация результата
Таблица или список соответствий в `field_mapping`.

### Короткий пример
`score` из формы должен записываться в `score` журнала без преобразования единиц или формата.

---

## Шаг 3. Правило маршрутизации
### Переход
После согласования полей требуется зафиксировать сам механизм назначения уровня.

### Почему шаг необходим
Правило маршрутизации должно быть идентично правилу из `A1`, иначе возникает расхождение между диагностикой и выдачей.

### Действие
Фиксируется `routing_rules(2/4/6)`:
- `0-2` -> `basic`
- `3-4` -> `standard`
- `5-6` -> `advanced`

### Ожидаемый результат
Назначение уровня в `A3` совпадает со шкалой в `A1`.

### Фиксация результата
Раздел `routing_rules(2/4/6)` в `A3`.

### Короткий пример
Для `score = 4` в журнале фиксируется `assigned_level = standard`.

---

## Шаг 4. Контрольные прогоны
### Переход
После настройки правил необходимо проверить поведение маршрута на тестовых сценариях.

### Почему шаг необходим
Конфигурация без прогона не подтверждает, что маршрутизация работает в реальном запуске.

### Действие
Выполняются сценарии:
1. `2/6` -> `basic`,
2. `4/6` -> `standard`,
3. `6/6` -> `advanced`.

### Ожидаемый результат
Каждый сценарий отражается в журнале с корректным уровнем.

### Фиксация результата
Разделы `run_evidence` и `result_log` в `A3`.

### Короткий пример
Строка журнала: `student_id=st-102, score=4, assigned_level=standard`.

---

## Минимальный состав строки журнала
`student_id`, `discipline`, `topic`, `score`, `assigned_level`, `material_link`, `timestamp`.

---

## Контроль завершения блока
1. Маршрут описан линейно и воспроизводимо.
2. Поля сопоставлены без потерь.
3. Три сценарных прогона подтверждены фактически.

# 05. Практика: обязательная часть A (A-core)

> Это главный практический файл темы.

---

## 🎯 Цель практики
Собрать адаптивный учебный модуль по своей дисциплине, который:
1. имеет 3 уровня (`basic`, `standard`, `advanced`);
2. назначает уровень по предтесту;
3. автоматически выдает уровень через `Albato`.

---

## 📦 Что сдавать
Сдача в **3 отдельных файлах**:
1. `A1` — паспорт модуля + предтест.
2. `A2` — комплект материалов трех уровней.
3. `A3` — протокол маршрутизации + подтверждение прогонов.

---

## 🧭 Шаг 1. Соберите A1
### Действие
Заполните поля:
`discipline`, `topic`, `audience`, `learning_goal`, `pretest_6q`, `answer_key`, `score`, `assigned_level`.

### Ожидаемый результат
Есть полный паспорт модуля и назначение уровня по шкале:
- `0-2` -> `basic`
- `3-4` -> `standard`
- `5-6` -> `advanced`

### Что сдавать
Файл `A1` в чистовом виде.

---

## 🧭 Шаг 2. Соберите A2
### Действие
Для каждого уровня (`basic`, `standard`, `advanced`) заполните:
`theory`, `practice_block`, `checkpoint_test`, `checkpoint_key`, `criteria`, `teacher_notes`.

### Ожидаемый результат
Три уровня реально отличаются по сложности и самостоятельности.

### Что сдавать
Файл `A2` с тремя уровнями.

---

## 🧭 Шаг 3. Проверьте checkpoint-блоки
### Действие
Проверьте, что на каждом уровне:
1. есть короткий `checkpoint_test`;
2. есть однозначный `checkpoint_key`;
3. checkpoint можно быстро проверить автоматически.

### Ожидаемый результат
Каждый уровень можно оперативно валидировать на занятии.

### Что сдавать
Обновленный `A2` с финальными checkpoint.

---

## 🧭 Шаг 4. Соберите A3 в Albato
### Действие
Настройте линейный поток:
`Yandex Forms -> Albato -> Google Sheets`.

В `A3` зафиксируйте:
1. `flow_steps`,
2. `field_mapping`,
3. `routing_rules(2/4/6)`.

### Ожидаемый результат
Назначение уровня работает автоматически без ручного переноса.

### Что сдавать
Черновик `A3` с описанием потока и маппингом полей.

---

## 🧭 Шаг 5. Подтвердите 3 сценарных прогона
### Действие
Сделайте тестовые кейсы:
1. `2/6` -> `basic`,
2. `4/6` -> `standard`,
3. `6/6` -> `advanced`.

Сохраните подтверждения в `run_evidence` и `result_log`.

### Ожидаемый результат
Все три кейса корректно маршрутизируются.

### Что сдавать
Финальный `A3` с подтвержденными прогонами.

---

## ✅ Что нельзя делать
1. Делать тему слишком широкой и абстрактной.
2. Назначать уровень без подсчета `score`.
3. Сдавать A2 без checkpoint и ключей.
4. Ограничиваться схемой Albato без реального прогона.

---

## 📝 Самопроверка перед сдачей A-core
1. Есть ли три отдельных файла `A1/A2/A3`?
2. Совпадает ли шкала уровней во всех файлах?
3. Подтверждены ли прогоны `2/6`, `4/6`, `6/6`?
4. Можно ли провести занятие по A2 без дополнительных объяснений?

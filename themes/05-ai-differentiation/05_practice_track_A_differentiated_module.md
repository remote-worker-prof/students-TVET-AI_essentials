# 05. Практика A-core: обязательный контур

---

## Назначение практики
Практика A-core предназначена для последовательной сборки обязательных артефактов `A1`, `A2`, `A3`.  
Результат считается завершенным при наличии фактических подтверждений маршрутизации.

---

## Состав сдачи
1. `A1` — паспорт модуля и предтест.
2. `A2` — три уровня материалов.
3. `A3` — протокол маршрутизации и журнал прогонов.

Формат сдачи: три отдельных файла.

---

## Шаг 1. Сборка A1
### Действие
Заполняются поля `A1`: `discipline`, `topic`, `audience`, `learning_goal`, `pretest_6q`, `answer_key`, `score`, `assigned_level`.

### Ожидаемый результат
Паспорт модуля и уровень сформированы на основе измеримого результата предтеста.

### Фиксация результата
Файл `A1` в завершенном виде.

---

## Шаг 2. Сборка A2
### Действие
Для уровней `basic`, `standard`, `advanced` заполняются поля:
`theory`, `practice_block`, `checkpoint_test`, `checkpoint_key`, `criteria`, `teacher_notes`.

### Ожидаемый результат
Уровни различаются по глубине учебных действий и имеют полный проверочный контур.

### Фиксация результата
Файл `A2` в завершенном виде.

---

## Шаг 3. Внутриуровневая проверка A2
### Действие
Проводится контроль наличия `checkpoint_test` и `checkpoint_key` во всех уровнях.

### Ожидаемый результат
Проверочный блок каждого уровня пригоден для однозначной валидации.

### Фиксация результата
Обновленный `A2` после внутренней проверки.

---

## Шаг 4. Сборка A3
### Действие
Формируется линейный маршрут `Yandex Forms -> Albato -> Google Sheets`; заполняются разделы `flow_steps`, `field_mapping`, `routing_rules(2/4/6)`.

### Ожидаемый результат
Маршрут обеспечивает автоматическое назначение уровня без ручной переинтерпретации данных.

### Фиксация результата
Черновой вариант `A3`.

---

## Шаг 5. Контрольные прогоны A3
### Действие
Проводятся прогоны `2/6`, `4/6`, `6/6` с фиксацией `run_evidence` и `result_log`.

### Ожидаемый результат
Все сценарии корректно отражаются в журнале с соответствующим уровнем.

### Фиксация результата
Финальный `A3`.

---

## Мини-шаблоны
### A1

```text
discipline:
topic:
audience:
learning_goal:
pretest_6q:
answer_key:
score:
assigned_level:
```

### A2

```text
level: basic|standard|advanced
theory:
practice_block:
checkpoint_test:
checkpoint_key:
criteria:
teacher_notes:
```

### A3

```text
flow_steps:
field_mapping:
routing_rules(2/4/6):
run_evidence:
result_log:
```

---

## Недопустимые решения
1. Смешение содержания нескольких дисциплин в одной теме.
2. Назначение уровня без вычисленного `score`.
3. Отсутствие `checkpoint_key` хотя бы в одном уровне.
4. Отчет о маршрутизации без фактического прогона.

---

## Контроль завершения A-core
1. Сохранены три отдельных файла `A1`, `A2`, `A3`.
2. Шкала уровня совпадает во всех файлах.
3. Сценарии `2/6`, `4/6`, `6/6` подтверждены в `result_log`.

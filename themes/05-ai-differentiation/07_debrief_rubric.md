# 07. Рубрика оценивания и формат защиты

---

## 🎯 Как читать рубрику
Каждый критерий оценивается по шкале `0-2`:
- `0` — не выполнено;
- `1` — выполнено частично;
- `2` — выполнено полностью и подтверждено фактами.

Максимум: `20` баллов.

---

## ✅ Рубрика (0-2 по каждому критерию)

| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| `A1`: паспорт модуля (`discipline/topic/audience/learning_goal`) | отсутствует | заполнен частично | заполнен полностью и конкретно |
| `A1`: предтест и ключ (`pretest_6q/answer_key`) | отсутствует | есть недочеты | 6 вопросов + корректный ключ |
| `A1`: назначение уровня | нет правила | правило указано, но применено с ошибками | уровень назначен строго по `0-2/3-4/5-6` |
| `A2`: полнота трех уровней | 1 уровень или фрагменты | 2 уровня или неполные блоки | все 3 уровня полные |
| `A2`: checkpoint в каждом уровне | отсутствует | есть не везде или без ключа | есть в каждом уровне и проверяем по ключу |
| `A2`: различимость уровней | уровни одинаковые | различия слабые | различия по сложности и самостоятельности ясные |
| `A3`: описание потока и маппинг | отсутствует | описано частично | есть `flow_steps` и `field_mapping` |
| `A3`: работоспособность маршрутизации | не подтверждена | подтверждена частично | подтверждены прогоны `2/6`, `4/6`, `6/6` |
| `A3`: корректность журнала | журнал отсутствует | есть неполные записи | есть минимальные поля в каждой записи |
| Часть B (гибрид light) | отсутствует | есть формально | есть фактическая доработка и подтверждение |

---

## 📦 Обязательные артефакты к защите
1. Файл `A1`.
2. Файл `A2`.
3. Файл `A3`.
4. Результат одного варианта части B.

---

## 🎯 Минимум для зачета
- Рекомендуемый минимум: `16` из `20`.
- Обязательные условия:
  1. критерий «`A1`: назначение уровня» = `2`;
  2. критерий «`A2`: полнота трех уровней» = `2`;
  3. критерий «`A3`: работоспособность маршрутизации» = `2`.

---

## 📝 Чек-лист быстрой проверки
1. Есть ли три отдельных файла `A1/A2/A3`?
2. Совпадает ли шкала уровней во всех файлах?
3. Есть ли checkpoint + key для каждого уровня?
4. Подтверждены ли три сценарных прогона?
5. Есть ли отдельный результат части B?

---

## 🧭 Формат защиты
1. Коротко показать `A1`: тема, предтест, назначение уровня.
2. Показать `A2`: различия `basic/standard/advanced`.
3. Показать `A3`: схема потока, лог и три прогона.
4. Показать улучшение из части B.

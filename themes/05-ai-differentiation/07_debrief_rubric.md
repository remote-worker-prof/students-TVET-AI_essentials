# 07. Рубрика оценивания результата

---

## Шкала оценки
Каждый критерий оценивается по шкале `0-2`:
- `0` — критерий не выполнен;
- `1` — критерий выполнен частично;
- `2` — критерий выполнен полностью и подтвержден артефактами.

Максимальная сумма: `20` баллов.

---

## Рубрика

| Критерий | 0 | 1 | 2 |
|---|---|---|---|
| `A1`: полнота паспорта модуля | отсутствует | заполнен частично | заполнен полностью |
| `A1`: корректность предтеста и ключа | отсутствуют | есть недочеты | предтест и ключ согласованы |
| `A1`: назначение уровня | правило не применено | правило применено с ошибками | применена шкала `0-2/3-4/5-6` |
| `A2`: полнота трех уровней | менее двух уровней | три уровня с пропусками | три полных уровня |
| `A2`: checkpoint-контур | отсутствует | неполный | checkpoint и ключ есть в каждом уровне |
| `A2`: различимость уровней | различий нет | различия частичные | различия выражены по сложности действий |
| `A3`: описание потока и маппинга | отсутствует | описано частично | описано полностью |
| `A3`: подтверждение прогонов | отсутствует | подтверждено частично | подтверждены `2/6`, `4/6`, `6/6` |
| `A3`: корректность журнала | отсутствует | поля неполные | поля соответствуют минимальному составу |
| Часть B | отсутствует | формальная доработка | доработка подтверждена фактически |

---

## Обязательные артефакты
1. Файл `A1`.
2. Файл `A2`.
3. Файл `A3`.
4. Результат вариативной части B.

---

## Порядок применения рубрики

| Этап | Действие | Ожидаемый результат | Фиксация результата |
|---|---|---|---|
| анализ `A1` | проверка полноты полей и шкалы уровня | формальная корректность входных данных | отметка по критериям `A1` |
| анализ `A2` | проверка структуры уровней и checkpoint | содержательная различимость уровней | отметка по критериям `A2` |
| анализ `A3` | проверка потока, прогонов и журнала | подтвержденная маршрутизация | отметка по критериям `A3` |
| анализ B | проверка фактической доработки | прирост качества без дублирования A-core | отметка по критерию B |

---

## Порог зачета
- Рекомендуемая сумма: не менее `16` из `20`.
- Обязательные условия:
  1. критерий назначения уровня в `A1` = `2`;
  2. критерий полноты `A2` = `2`;
  3. критерий подтверждения прогонов в `A3` = `2`.

---

## Контрольный чек-лист
1. Присутствуют ли все обязательные артефакты?
2. Соблюдена ли единая шкала уровней?
3. Подтверждены ли три сценарных прогона?
4. Имеет ли часть B проверяемый результат?

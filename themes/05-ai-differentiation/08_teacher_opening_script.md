# 08. Вводный сценарий запуска темы (внутренний файл)

---

## 🎯 Текст открытия (2-4 минуты)
Сегодня вы не просто делаете задания, а собираете адаптивный мини-модуль по своей дисциплине и теме.

На выходе у каждого будет:
1. `A1` — паспорт + предтест;
2. `A2` — три уровня материалов;
3. `A3` — работающий маршрут выдачи уровня через Albato.

Ваш уровень назначается по предтесту:
- `0-2` -> `basic`,
- `3-4` -> `standard`,
- `5-6` -> `advanced`.

---

## 🧭 Порядок действий на старте
1. Утверждаем `discipline/topic/audience/learning_goal`.
2. Собираем `A1` и фиксируем уровень.
3. Собираем `A2` с checkpoint для каждого уровня.
4. Настраиваем `A3`: `Yandex Forms -> Albato -> Google Sheets`.
5. Проверяем прогоны `2/6`, `4/6`, `6/6`.
6. Делаем один light-вариант части B.

---

## ⚙️ Обязательный минимум автоматизации
Albato — обязательный элемент части A, но логика остается линейной и понятной.

---

## 📦 Что должно быть к защите
1. Три файла: `A1`, `A2`, `A3`.
2. Подтверждение трех прогонов маршрутизации.
3. Один результат части B.

# 09. Интегрированный сценарий на 90 минут

---

## Результат занятия
К завершению занятия формируются:
1. `A1` — паспорт и предтест с назначенным уровнем.
2. `A2` — три уровня материалов с checkpoint-контуром.
3. `A3` — рабочая маршрутизация с подтвержденными прогонами.

---

## Ключевые понятия
- `адаптивный модуль`: комплект материалов с вариативностью по уровню сложности.  
  Назначение: обеспечивает соответствие содержимого исходной подготовке.
- `маршрутизация`: автоматическое сопоставление балла предтеста и уровня выдачи.  
  Назначение: устраняет субъективность распределения.
- `артефакт`: проверяемый документированный результат этапа.  
  Назначение: фиксирует состояние выполнения без устных пояснений.

---

## Тайминг занятия

| Интервал | Блок | Целевое действие | Выходной артефакт |
|---|---|---|---|
| 0-10 | запуск | фиксация регламента | зафиксирован план действий |
| 10-35 | A1 | сборка паспорта и предтеста | черновик `A1` |
| 35-60 | A2 | проектирование уровней | черновик `A2` |
| 60-75 | A3 | настройка линейного потока | черновик `A3` |
| 75-85 | контроль | сценарные прогоны | `run_evidence`, `result_log` |
| 85-90 | итог | сверка состава сдачи | финальные версии `A1/A2/A3` |

---

## Блок 1. Сборка A1
### Действие
Заполняются поля `A1`, формируется `pretest_6q`, подсчитывается `score`, фиксируется `assigned_level`.

### Ожидаемый результат
Уровень назначен строго по формальной шкале.

### Фиксация результата
Заполненный артефакт `A1`.

---

## Блок 2. Сборка A2
### Действие
Для каждого уровня формируются `theory`, `practice_block`, `checkpoint_test`, `checkpoint_key`, `criteria`, `teacher_notes`.

### Ожидаемый результат
Уровни различаются по требуемому типу учебного действия.

### Фиксация результата
Заполненный артефакт `A2`.

---

## Блок 3. Сборка A3
### Действие
Описывается и настраивается поток `Yandex Forms -> Albato -> Google Sheets`; фиксируются `flow_steps`, `field_mapping`, `routing_rules(2/4/6)`.

### Ожидаемый результат
Маршрут обеспечивает однозначную регистрацию результата предтеста.

### Фиксация результата
Черновой артефакт `A3`.

---

## Блок 4. Контрольные прогоны
### Действие
Выполняются тестовые сценарии:
1. `2/6` -> `basic`,
2. `4/6` -> `standard`,
3. `6/6` -> `advanced`.

### Ожидаемый результат
Все сценарии отражены в журнале без расхождения с правилами маршрутизации.

### Фиксация результата
Разделы `run_evidence` и `result_log` в `A3`.

---

## Выходной контроль занятия
1. Сформированы три отдельных файла `A1`, `A2`, `A3`.
2. Поля артефактов соответствуют контракту.
3. Шкала уровня применена единообразно.
4. Подтверждены три сценарных прогона.

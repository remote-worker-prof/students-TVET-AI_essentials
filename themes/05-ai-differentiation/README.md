# Материалы темы `05-ai-differentiation`

> Стартуйте с [01_student_start_here.md](01_student_start_here.md).

---

## 🎯 Что делаем в этой теме
Студент педагогического направления проектирует адаптивный мини-модуль по **своей дисциплине и узкой теме**:
- `basic`,
- `standard`,
- `advanced`.

Назначение уровня делается через предтест и обязательную маршрутизацию в `Albato`.

---

## 📦 Обязательный результат части A
Вместо старого табличного контура используются 3 артефакта:
1. `A1` — паспорт модуля + предтест.
2. `A2` — комплект материалов для трех уровней.
3. `A3` — протокол маршрутизации `Yandex Forms -> Albato -> Google Sheets` и подтверждение прогонов.

---

## 🧪 Правило предтеста
- предтест: `6` вопросов;
- шкала назначения уровня:
  - `0-2` -> `basic`,
  - `3-4` -> `standard`,
  - `5-6` -> `advanced`.

---

## 🧱 Что обязательно есть в уровне
Для каждого уровня (`basic`, `standard`, `advanced`) фиксируются поля:
- `theory`,
- `practice_block`,
- `checkpoint_test`,
- `checkpoint_key`,
- `criteria`,
- `teacher_notes`.

`checkpoint_test` обязателен для каждого уровня и должен быть проверяем по ключу.

---

## ⚙️ Обязательный стек маршрутизации
Линейный маршрут без сложной автоматики:
`Yandex Forms -> Albato -> Google Sheets`.

Минимальная запись в логе:
`student_id`, `discipline`, `topic`, `score`, `assigned_level`, `material_link`, `timestamp`.

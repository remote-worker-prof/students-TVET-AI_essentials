# Материалы темы `05-ai-differentiation`

> Стартовая точка: [01_student_start_here.md](01_student_start_here.md).

---

## 🎯 Назначение темы
Тема предназначена для проектирования адаптивного учебного мини-модуля по индивидуально выбранной дисциплине и узкой теме.  
В основе темы лежит единый контракт артефактов `A1/A2/A3` и обязательная линейная маршрутизация через `Albato`.

---

## 📦 Состав обязательного результата
1. `A1` — паспорт модуля и предтест.
2. `A2` — комплект материалов трех уровней (`basic`, `standard`, `advanced`).
3. `A3` — протокол маршрутизации `Yandex Forms -> Albato -> Google Sheets` и подтвержденные прогоны.

---

## 🧪 Правило назначения уровня
Предтест содержит `6` вопросов. Уровень назначается по шкале:
- `0-2` -> `basic`,
- `3-4` -> `standard`,
- `5-6` -> `advanced`.

---

## ⚙️ Контракт полей
- `A1`: `discipline`, `topic`, `audience`, `learning_goal`, `pretest_6q`, `answer_key`, `score`, `assigned_level`.
- `A2`: `theory`, `practice_block`, `checkpoint_test`, `checkpoint_key`, `criteria`, `teacher_notes`.
- `A3`: `flow_steps`, `field_mapping`, `routing_rules(2/4/6)`, `run_evidence`, `result_log`.

Минимальная строка журнала:
`student_id`, `discipline`, `topic`, `score`, `assigned_level`, `material_link`, `timestamp`.

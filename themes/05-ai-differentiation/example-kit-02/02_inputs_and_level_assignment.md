# 02. Входные данные и назначение уровня

---

## Назначение файла
Файл фиксирует обязательный набор параметров для `A1` и правило вычисления итогового уровня.

---

## Шаблон A1

```text
discipline:
topic:
audience:
learning_goal:
pretest_6q:
answer_key:
score:
assigned_level:
```

---

## Правило шкалы
- `0-2` -> `basic`
- `3-4` -> `standard`
- `5-6` -> `advanced`

---

## Контроль полноты
1. Параметры контекста заполнены.
2. Предтест содержит шесть вопросов.
3. Ключ ответов присутствует.
4. `assigned_level` соответствует `score`.

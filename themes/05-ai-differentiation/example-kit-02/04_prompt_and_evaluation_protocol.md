# 04. Протокол генерации и проверки (обезличенный)

---

## Назначение файла
Файл задает формальный протокол получения контента `A2` и минимальный контур его проверки.

---

## Каркас запроса

```text
Роль: методический ассистент СПО.

Вход:
discipline:
topic:
audience:
learning_goal:
level:

Выход:
theory
practice_block
checkpoint_test
checkpoint_key
criteria
teacher_notes
```

---

## Контур проверки
1. Наличие всех полей результата.
2. Соответствие содержания заявленному уровню.
3. Проверяемость checkpoint по ключу.
4. Отсутствие выхода за предметные границы темы.

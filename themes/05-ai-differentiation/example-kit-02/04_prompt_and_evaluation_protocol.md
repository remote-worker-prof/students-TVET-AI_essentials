# 04. Протокол промптинга и проверки (обезличенный)

---

## Каркас промпта

```text
Роль: методический ассистент СПО.

Вход:
- discipline
- topic
- audience
- learning_goal
- level

Собери блок уровня в формате:
theory
practice_block
checkpoint_test
checkpoint_key
criteria
teacher_notes
```

---

## Короткая проверка ответа
1. Есть все 6 полей?
2. Уровень соответствует сложности?
3. Checkpoint проверяется по ключу?
4. Текст пригоден для использования на занятии?

# 04. Протокол генерации и проверки

---

## Назначение файла
Файл задает формальный протокол получения содержимого `A2` с последующей валидацией качества.

---

## Ключевые понятия
- `протокол генерации`: фиксированный порядок формирования ответа модели.  
  Назначение: обеспечивает повторяемость структуры.
- `валидация`: последовательная проверка полноты и корректности блока.  
  Назначение: предотвращает использование неполного результата.

---

## Каркас промпта

```text
Роль: методический ассистент СПО.

Входные поля:
discipline:
topic:
audience:
learning_goal:
level:

Требуется сформировать:
1) theory
2) practice_block
3) checkpoint_test
4) checkpoint_key
5) criteria
6) teacher_notes

Ограничения:
- соответствие заявленной теме;
- отсутствие внешних отклоняющихся тем;
- проверяемость checkpoint по ключу.
```

---

## Контур проверки результата
1. Проверка полноты всех шести полей.
2. Проверка соответствия уровня заявленной сложности.
3. Проверка однозначности `checkpoint_key`.
4. Проверка формулировок `criteria` на отсутствие оценочной размытости.

---

## Итерационный принцип
При обнаружении дефекта изменяется один параметр промпта за одну итерацию с фиксацией эффекта.

## ✅ Quality gate перед сдачей
1. В `A1` заполнены все поля и уровень назначен по шкале `0-2/3-4/5-6`.
2. В `A2` есть три уровня и checkpoint + key для каждого.
3. В `A3` описан поток, маппинг и есть 3 подтвержденных прогона.
4. В логе есть поля: `student_id`, `discipline`, `topic`, `score`, `assigned_level`, `material_link`, `timestamp`.
